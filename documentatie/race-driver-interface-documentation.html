Abstract

This document details the development and implementation of two complementary interface systems designed for professional race drivers: a Car Mobile Interface Application and an Augmented Reality (AR) Helmet Interface Application. These systems work in tandem to enhance driver performance, safety, and overall racing experience across multiple racing disciplines including NASCAR, WRC, Formula 1, and other professional motorsport categories.

race driver interface augmented reality mobile interface motorsport technology driver safety HUD user experience

1. Introduction

Modern motorsport requires drivers to process enormous amounts of information while maintaining focus on driving at the absolute limit of performance. The integration of digital interfaces has revolutionized how drivers interact with their vehicles, providing critical data without distracting from the primary task of racing.

This project introduces two complementary interface systems:

  1. Car Mobile Interface Application:A mobile application to help the user track important information like car status, weather, expenses, news, contact innformation for managers/mechanics, etc.
  2. AR Helmet Interface Application: An augmented reality heads-up display (HUD) integrated into the driver's helmet, providing critical information directly in the field of vision.

Together, these systems represent a comprehensive approach to race driver interaction design that prioritizes accessibility, safety, and performance enhancement.

2. Methodology

Our design and development approach was guided by extensive research especially literature research and competition analysis.

2. Research Process

The development followed a user-centered design process including:

  • Literature research to familiarize ourselves with the world of racing.
  • Analysis of existing competition to figure out what we can expand upon.
  • Creating personas to know what type of users we expect.
  • Creating a unified style to use for the app(fonts, colors, dimensions).
  • Creating interactive prototypes to showcase our app.

3. Car Mobile Interface Application

The Car Mobile Interface is designed to help the user in navigating various neccessary information to use in races.

3.1 Key Features

Main Page

Containing this information:

  • News
  • A drivers log
  • Performance overview

Race Page

Contains information like:

  • The current season/Team information/Strategy
  • Date and location of the race
  • Informations about the track
  • Rival drivers overview

Car Page

Features:

  • Core performance specs
  • Setup settings for car systems
  • Strategy highlights

Weather Page

Containing various weather related information like:

  • Temperature
  • Wind
  • Humidity
  • A weather forecast
  • Weather alerts

Expenses Page

Containing information about:

  • Expenses overview
  • Budget overview
  • Expense tracking

Contact Section

Containing information about:

  • Driver contact information
  • Mechanics contact information
  • Manager contact information

Profile Page

Containing various information about the user:

  • Basic info
  • Performance stats
  • Recent Activity

Login/Register Page

Allows a user to input the necessary information to login/create an account

Side Menu

Used to navigate through the numerous pages

3.2 User Flow

The application follows a hierarchical structure with the following primary flows:

Main Navigation Flows:

The interface is structured around authentication states and user engagement screens, branching into functional modules:

  • Authentication Flow:
    • Logged out → Register / Login Page → Forgot Password Page (if needed)
    • Login success → Logged in
  • Post-Login Flow:
    • Logged in → Homescreen → Start Race Page → VR Headset Pages
    • VR Headset Pages →
      • Race Screen
      • Critical Failure Screen
      • Warning Page
      • Pitstop Screen
  • Settings and Information Flow:
    • Homescreen → Settings Page →
      • Account Settings
      • User Settings
      • Headset VR Controls
    • Homescreen → News / Rivals Page / Location Map Page / Weather Page / Contact Team Page
  • Static Utility Pages:
    • About Us
    • Terms and Conditions

4. AR Helmet Interface Application

The AR Helmet Interface supplements the touch interface by providing critical information directly in the driver's field of vision, eliminating the need to look away from the track.

4.1 Key Features

Primary Racing HUD

Essential information displayed in the driver's line of sight:

  • A minimap of the track
  • A leaderboard
  • Current position and lap time of the driver
  • Icons representing weather conditions, flag color warnings, car status, tyre condition

5. Conclusion

The integrated Car Mobile Interface and AR Helmet Interface system represents a significant advancement in race driver information systems. By combining intuitive touch controls with non-intrusive augmented reality information delivery, the system provides comprehensive support for professional race drivers while maintaining focus on the fundamental task of racing.

As motorsport continues to evolve with increasing technological integration, interface design that balances information delivery with driver focus will remain critical to competitive performance and safety. This system establishes a framework for future developments in this vital area of racing technology.
